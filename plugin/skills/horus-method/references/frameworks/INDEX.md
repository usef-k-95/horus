# Frameworks catalogue index

One file per framework, organised by the phase in which Horus most often reaches for it. Each file follows the fixed sections in CONVENTIONS.md: what it is, when Horus uses it, steps, outputs mapped to state records, pitfalls, source. Pathway packs in `horus-policy/references/pathways/` point into this catalogue by id.

When Horus uses this: at P1 to select frameworks into `approach.frameworks[]` with a rationale per id, and whenever a worker brief or an analysis record needs a method reference.

## Selection rules

- Select frameworks per phase from the primary pathway pack's Frameworks section first; add from a secondary pack only for the component it governs.
- Record every selection in `approach.frameworks[] {id, name, source_org, rationale, used_in_phases[]}` and cite the id in `analyses.frameworks[]` on each analysis that applies it.
- Prefer the fewest frameworks that cover the issue tree; a kickoff deck that names more than six is usually hiding a missing hypothesis.
- Where a framework's Source line cites BENCHMARKS.md, quote the standard from the catalogue entry, not from memory, and respect its verification marks.
