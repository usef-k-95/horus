# Fixture engagement (synthetic)

A realistic but fictional request for proposals used for development, evals and demos. The country, ministry and people are invented; any resemblance to real officials is unintended. Nothing here should be treated as evidence about the real world.

- `rfp.md`: the request for proposals from the fictional Ministry of Finance of the Republic of Meridia for a national SME e-invoicing and digitalisation policy. It classifies as the strategy pathway with a regulatory secondary pathway.
- `pm-email-1.md`: the client project manager's first email, with instructions and two attachments named (not supplied).
- `scaffold.sh`: initialises an engagement in the current folder and imports the RFP; used by eval cases and demos.
